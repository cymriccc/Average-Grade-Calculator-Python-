# 🧮 Average Grade Calculator (Activity 5)

A simple **Python program** that calculates a student’s average grade across multiple subjects.  
This program demonstrates **user input handling**, **basic arithmetic operations**, and **text styling using Colorama** for colorful terminal output.

---

## 💡 Features
- ✏️ Input grades for multiple subjects (Math, Science, English, Filipino)  
- 🧠 Automatically computes the average grade  
- 🎨 Colorful output using `colorama`  
- 💬 Personalized greeting with the user’s name  

---

## 📦 Installation

1. **Clone or Download** this repository.  
   ```bash
   git clone https://github.com/<your-username>/AverageGradeCalculator.git
   ```
   *(or download the ZIP file and extract it)*

2. **Navigate** to the project folder:
   ```bash
   cd AverageGradeCalculator
   ```

3. **Install dependencies** (requires Python 3):
   ```bash
   pip install colorama
   ```

4. **Run the program**:
   ```bash
   python AverageGradeCalculator.py
   ```

---

## 🧰 Requirements
- Python 3.8 or higher  
- `colorama` library (`pip install colorama`)

---

## 🧠 How It Works
1. The user is asked to enter their **name** and **grades** for 4 subjects.  
2. The program calculates the **average** using:
   ```python
   average = (math + science + english + filipino) / 4
   ```
3. It then displays the result with styled colored text in the terminal.
